# House Price Prediction

## Project Overview

This project predicts house prices using Python and Machine Learning.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset

The dataset contains house information such as:

- Area
- Bedrooms
- Bathrooms
- Age
- Price

This project uses a small sample dataset for learning and demonstration purposes.

## Data Analysis

Performed:

- Data checking
- Missing value analysis
- Duplicate checking
- Basic statistical analysis
- Data visualization

## Machine Learning

A Linear Regression model was trained to predict house prices using:

- Area
- Bedrooms
- Bathrooms
- Age

## Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

Results on the small test set:

- MAE: ₹386,697.64
- MSE: 168,117,540,246.64
- R² Score: 0.9874

Because the dataset is very small, these results are for learning and demonstration purposes and should not be treated as real-world performance.

## New House Prediction

For a house with:

- Area: 1600 sq ft
- Bedrooms: 3
- Bathrooms: 2
- Age: 6 years

Predicted price: approximately ₹53.2 lakh.

## Conclusion

This project demonstrates how Python, data analysis, visualization, and Linear Regression can be used to predict house prices.
